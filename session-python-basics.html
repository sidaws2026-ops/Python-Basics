What is a program?

A program is a list of steps written for the computer. The computer does them from top to bottom, exactly as written. It never guesses what you meant.

Think of it like: A recipe. Follow the steps in order and you get the dish. Miss a step and it goes wrong.

print() shows something on the screen. A line starting with # is a note for humans, and the computer skips it.

Example 1.1
# This is a note. The computer skips this line.
print("Namaskara, Bengaluru!")
print("Two idli", "one coffee")
print()
print("Total: Rs", 40 + 25)
Show output
Namaskara, Bengaluru!
Two idli one coffee

Total: Rs 65

print() has two helpers. sep chooses what goes between values, and end chooses what goes at the end of the line.

Example 1.2
print("Mysuru", "Mandya", "Bengaluru", sep=" to ")
print("Loading", end="...")
print("done")
Show output
Mysuru to Mandya to Bengaluru
Loading...done

Variables: giving a value a name

A variable is a name for a value, so you can use it again later. You can also change what's inside at any time.

Think of it like: A labelled steel dabba. The label says sugar. What's inside can change, but you still find it by the label.

We save a shop name, the number of cups and the price of one cup. Then we use those names to work out the bill.

Example 1.3
shop = "Raju Tea Stall"
cups = 2
price = 15

print(shop)
print(cups * price)

Good names explain themselves: total_price, pincode, is_paid. A name can't start with a number or contain spaces, and Price and price are two different names.

You can name several values in one line, and swap two values without a third name. It's like two friends swapping seats.

Example 1.4
morning_tea, evening_tea = 20, 35
print(morning_tea, evening_tea)

morning_tea, evening_tea = evening_tea, morning_tea

Text and numbers don't mix by themselves

To Python, "5" in quotes is text, and 5 is a number. Adding two pieces of text just puts them side by side. To do maths on text, convert it first.

Think of it like: A phone number. It's made of digits, but you'd never add two phone numbers together.

See the difference, then use int(), float() and str() to change a value from one type to another.

print(str(500) + " rupees")    # str() makes text

print(bool(0), bool(7))        # bool(): 0 is False, others are True
print(isinstance(45, int))     # Is 45 a whole number?

f-strings: filling in the blanks

Put the letter f before the quotes, then put any name or calculation inside { }. Python fills in the value. You'll use this in almost every program.

Think of it like: A form letter: "Dear ____, your bill is Rs ____." Python fills in the blanks.

A shop bill line, filled in automatically. :.2f means "show 2 decimal places", and :, adds commas to big numbers.

Example 1.17
item = "Filter coffee"
cups = 3
price = 30

print(f"{cups} x {item} = Rs {cups * price}")

print(f"Pay Rs {1234.5:.2f}")
print(f"Salary: Rs {100000:,}")
Show output
3 x Filter coffee = Rs 90
Pay Rs 1234.50
Salary: Rs 100,000

You can round, add commas or keep things lined up inside an f-string. :<14 keeps a value on the left of a space 14 characters wide, and :>6 keeps it on the right of a space 6 wide.

Example 1.18
print(f"{'Idli':<14}{30:>6}")
print(f"{'Masala dosa':<14}{60:>6}")
print(f"Marks: {87.456:.1f}")
Show output
Idli              30
Masala dosa       60
Marks: 87.5

Tuples: a list that can't change

A tuple is like a list, but once it's made, it can't be changed. Write it with round brackets ( ). Use it for values that belong together and should stay fixed. To "add" a value, you make a new tuple, and the examples below show you how.

Think of it like: A printed wedding card. You can't add a name to a card that's already printed, but you can print a new card with the extra name.

A date of birth stored as a tuple. You can read it, and you can "unpack" it, which means giving each value its own name in one line.

Example 2.9
birthday = (15, "August", 1998)

print(birthday[1])
print(len(birthday))

day, month, year = birthday      # Unpacking
print(f"Born in {month} {year}")

3

birthday[0] = 20

Example 2.12

Sets: no repeats

A set keeps each value only once, and in no fixed order. Use it to remove repeats or to compare two groups.

Think of it like: An attendance register. However many times a student walks in, their name counts once.

Students who came to class, with some names repeated. A set removes the repeats. sorted() puts them in A to Z order, so they're easy to read.

Example 2.16
entries = ["Asha", "Ravi", "Asha", "Meena", "Ravi"]

present = set(entries)
print(len(entries), len(present))
print(sorted(present))
print("Meena" in present)
Show output
5 3
['Asha', 'Meena', 'Ravi']
True

Compare two groups of friends: who's in both, who's in either, and who's only in the first.

Example 2.17
cricket = {"Asha", "Ravi", "Meena"}
music = {"Ravi", "Meena", "Kiran"}

print(sorted(cricket & music))    # In both groups
print(sorted(cricket | music))    # In either group
print(sorted(cricket - music))    # Only in cricket
Show output
['Meena', 'Ravi']
['Asha', 'Kiran', 'Meena', 'Ravi']
['Asha']

Changing a set: add() puts in one value, update() puts in many, and remove() and discard() take one out. The difference is that remove() crashes if the value is missing, and discard() doesn't.

Example 2.18
present = set()              # An empty set. {} would make a dictionary
present.add("Asha")
present.add("Ravi")
present.add("Asha")          # Already there, so nothing changes
print(sorted(present))

present.update(["Meena", "Kiran"])
print(sorted(present))

present.remove("Ravi")
present.discard("Sunil")     # Not there, and no crash
print(sorted(present))

for name in sorted(present):
    print(f"Present: {name}")
Show output
['Asha', 'Ravi']
['Asha', 'Kiran', 'Meena', 'Ravi']
['Asha', 'Kiran', 'Meena']
Present: Asha
Present: Kiran
Present: Meena

A set has no positions, so present[0] gives a TypeError. If you need positions, use a list.

Dictionaries: look up by name

A dictionary stores pairs: a key, which is what you look up, and a value, which is what you get back. Write it with curly brackets { }. This is the most important type in this course, because most of the data AI tools send back looks like this.

Think of it like: A hotel menu. Find the dish name (the key) and you get the price (the value).

A darshini menu. Look up a price, add a dish, change a price and remove a dish.

Example 2.19
menu = {"idli": 30, "dosa": 60, "coffee": 25}

Type hints are labels that say what a function expects and gives back. A sentence in triple quotes at the top, called a docstring, says what it does. Python doesn't enforce them, but they help people read your code, and a tool you'll meet later, Pydantic, depends on them.

Think of it like: The label on a medicine bottle: what it's for and how much to take.

try and except: planning for problems

try means "attempt this". except means "if that goes wrong, do this instead". The program carries on rather than crashing.

Think of it like: "Try the UPI payment. If it fails, take cash." The sale still happens.

Someone types a word where we need a number. Instead of a crash, they get a helpful message.

Example 5.2
text = input("How many tickets? ")

try:
    tickets = int(text)
    print(f"Booking {tickets} tickets")
except ValueError:
    print("Please type a number, like 2")

print("Thank you for using our app")

Sample run, typing: abc

Show output

You can plan for different problems. else runs if nothing went wrong, and finally always runs, like "close the shop at the end, no matter what".

Example 5.3
menu = {"idli": 30, "dosa": 60}
dish = "pizza"
friends = 0

try:
    print(menu[dish] / friends)
except KeyError:
    print("That dish isn't on the menu")
except ZeroDivisionError:
    print("Nobody to split the bill with")
else:
    print("All good")
finally:
    print("Closing the bill")
Show output
That dish isn't on the menu
Closing the bill

You can raise your own error when something doesn't make sense, like a cinema refusing to book minus 2 tickets. as problem gives the error message a name, so you can print it.

Putting it all together: a kirana shop bill

This small program uses nearly everything from this session. It asks for a PIN code, takes an order, prints a bill and saves it. Read it one function at a time, and try to say what each one does in your own words.

A fictional shop's checkout. In the sample run, the person first types a wrong PIN code, then asks for something the shop doesn't sell, then types a word instead of a number.

Example 5.13
import json

MENU = {"rice": 62, "dal": 145, "milk": 28, "coffee": 95}


def ask_pin():
    pin = input("PIN code: ").strip()
    while not (pin.isdigit() and len(pin) == 6):
        print("A PIN code has exactly 6 digits.")
        pin = input("PIN code: ").strip()
    return pin


def ask_quantity(item):
    try:
        return int(input(f"How many {item}? "))
    except ValueError:
        print("That isn't a number, so we'll use 1.")
        return 1


def take_order():
    cart = []
    while True:
        item = input("Item (or done): ").strip().lower()
        if item == "done":
            break
        if item not in MENU:
            print(f"Sorry, we only have: {', '.join(MENU)}")
            continue
        quantity = ask_quantity(item)
        cart.append({"item": item, "quantity": quantity, "cost": quantity * MENU[item]})
    return cart


def delivery_charge(subtotal):
    return 0 if subtotal >= 500 else 40


pin = ask_pin()
cart = take_order()

subtotal = sum(line["cost"] for line in cart)
charge = delivery_charge(subtotal)

print("\n--- Your bill ---")
for line in cart:
    print(f"{line['quantity']} x {line['item']}: Rs {line['cost']}")
print(f"Delivery: Rs {charge}")
print(f"Total: Rs {subtotal + charge}")

order = {"pin": pin, "cart": cart, "total": subtotal + charge}
with open("last_order.json", "w", encoding="utf-8") as file:
    json.dump(order, file, indent=2)
print("Saved to last_order.json")
